# TaskPilot

**TaskPilot** is an AI-powered task and project management web application that helps teams collaborate efficiently. Designed as a full SaaS platform, it features secure authentication, a RESTful API, a PostgreSQL database, a responsive UI, and AWS deployment.

---

## Features

- 🔐 Auth (NextAuth.js + PostgreSQL)
- 📋 Project & Task Boards
- 🤖 AI-powered task generation
- 🔄 RESTful API with full CRUD
- ✅ Unit, Integration, and E2E testing
- ☁️ AWS Deployment (EC2, RDS, S3)
- 🧑‍💻 Admin/User role-based permissions

---

## Tech Stack

| Area | Technology |
|------|------------|
| Frontend | Next.js 14 (App Router), TypeScript, Tailwind, Shadcn UI |
| Backend | REST API (Next API routes or Express), Zod, Prisma |
| Auth | NextAuth.js with JWT (httpOnly cookies) |
| Database | PostgreSQL (Supabase for dev, AWS RDS for prod) |
| Deployment | AWS (EC2, RDS, S3, Route 53) |
| Testing | Jest/Vitest, Cypress, GitHub Actions CI |
